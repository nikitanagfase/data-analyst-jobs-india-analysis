## 📌 Project Overview

This project analyzes the **Data Analyst Job Market in India** using a real-world Kaggle dataset. The goal is to perform an end-to-end data analytics workflow—from data cleaning and SQL analysis to dashboard development—to identify hiring trends, required skills, salary transparency, and opportunities for entry-level candidates.

---

## 🎯 Objectives

- Analyze city-wise demand for Data Analysts
- Identify the most in-demand technical skills
- Study salary disclosure trends
- Explore hiring opportunities for freshers
- Build an interactive Power BI dashboard
